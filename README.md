# Teyvat Tracker

Трекер досягнень і круток Genshin Impact для Windows і Android. Працює без реклами, дані зберігаються на вашому пристрої.

## Завантажити
Останню версію беріть у розділі [Releases](https://github.com/miat09/teyvat-tracker/releases/latest):
- Windows: `Teyvat_Tracker_…_Windows_Setup.exe`
- Android: `Teyvat_Tracker_…_Android.apk`

## Що вміє
- Досягнення з гайдами «як виконати» (українська, російська, англійська, польська)
- Крутки: історія, гарант, планувальник
- Помічник Сяо: підказки й маршрути
- Імпорт з Genshin Center, Paimon.moe, UIAF, UIGF
- Синхронізація ПК і телефона через Google Drive
- Оновлення прямо в програмі: Налаштування → Оновлення програми

Нові версії з'являються в Releases, оновлення можна отримати в самій програмі.
